## How to run the cars EDA notebook

1. Download or clone this repository.
2. Keep `Cars_data_.csv` in the same folder as the EDA notebook.
3. Install dependencies:

```bash
pip install pandas numpy matplotlib seaborn jupyter
```

4. Start Jupyter:

```bash
jupyter notebook
```

5. Open `Cars_Dataset_EDA_Portfolio.ipynb` and run all cells in order.

You can also use Google Colab and upload the CSV file.
