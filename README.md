## Projects and coursework

### 1. Car Dataset — Exploratory Data Analysis
**Notebook:** [Exploratory_Data_Analysis_Assignment.ipynb](./Exploratory_Data_Analysis_Assignment.ipynb)  
**Dataset:** [Cars_data_.csv](./Cars_data_.csv)

An exploratory analysis of vehicle data focused on data quality, price distributions, manufacturer comparisons, vehicle specifications, and numeric correlations.

The notebook covers:
- Dataset structure and data types
- Missing-value and duplicate checks
- Data cleaning and IQR-based outlier filtering
- Price and horsepower distributions
- Manufacturer and transmission comparisons
- Correlation analysis
- A data-driven summary, conclusions, and limitations

> Run the notebook from top to bottom to generate the analysis. Findings should be based on the outputs produced by the dataset. This is an EDA project, not a trained price-prediction model.

## How to run the car EDA notebook

1. Download or clone this repository.
2. Keep `Cars_data_.csv` in the repository root (beside the notebook).
3. Install the required packages:

```bash
pip install pandas numpy matplotlib seaborn scipy jupyter
```

4. Open the notebook in Google Colab or Jupyter and run all cells in order.
